# animal-clinic-project
IA para gerenciamento de tarefas admisnitrativas. 

# Projeto de Agendamento de Consultas

## Instruções para Instalação

### Requisitos
- Node.js
- MySQL

### Backend
1. Acesse o diretório `backend`.
2. Instale as dependências: `npm install`.
3. Configure o banco de dados MySQL no arquivo `backend/config/db.js`.
4. Execute o servidor: `node server.js`.

### Frontend
1. Acesse o diretório `frontend`.
2. Instale as dependências: `npm install`.
3. Execute o projeto: `npm start`.

## Funcionalidades
- Agendar consultas.
- Editar ou cancelar consultas.
- Validações de dados e disponibilidade de horários.
